# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories:
<https://github.com/kaiy0ri/sask/security/advisories/new>

Do not open a public issue for a suspected vulnerability. Include affected version or commit, reproduction steps and impact. We aim to acknowledge reports within a few days.

## Scope

In scope: sask code, its sandbox (isolation escapes are the highest priority), and its CI configuration.

Out of scope: `tests/fixtures/vulnerable-app/`. Its vulnerabilities are intentional.

## Supported versions

Pre-alpha. Only `main` is supported.
